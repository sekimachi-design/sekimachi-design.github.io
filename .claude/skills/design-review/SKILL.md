---
name: design-review
description: 新規・変更したページを公開前にチェックする。「公開前に見て」「スマホで崩れてない?」「リンク切れ確認」などで使う。
---
1. `git diff --stat` と `git status` で変更範囲を確認する。
2. `design-reviewer` エージェントに変更ファイルを渡してレビューさせる。
3. 指摘のうち「高」は修正案を Rie さんに示し、了承を得てから直す(既存ファイルは削除しない)。
4. 必要なら `python3 -m http.server` で起動し、Playwright でスマホ幅のスクリーンショットを撮って確認する。
5. 結果を「直したもの / 残したもの / 要確認」で短く報告する。
